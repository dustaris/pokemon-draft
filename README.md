# Build a 13-0 Team (Pokémon)

Browser draft game: spin a region, draft a Pokémon into each of 6 roles, sign a trainer, then run 8 Gyms, the Elite Four and the Champion.

- `index.html`: the game (written for the Claude artifact wrapper)
- `dex.js`, `sprites.js`: generated by `build/make_data.py` (needs `build/pokedex.json` from Showdown and `build/sprites/` from PokéAPI)
- `docs/`: the GitHub Pages site, rebuilt with `build/make_site.sh`
